## 01 / Information baseline

# Controls before production.

Add dependable Revit capacity without fragmenting model standards, annotation conventions or drawing-set coordination.

### Required inputs

- Approved mark-ups and design information
- Revit template and content standards
- Sheet register and documentation protocol
- Model ownership and worksharing plan

### Naming and controls

- Client template, shared parameters and content-library rules
- View, sheet, schedule, family and type naming conventions
- Workset, link, ownership, synchronization and backup protocol
- Sheet register, revision route and named checker/approver

### Standards and constraints

- Approved design information and mark-ups remain the production authority
- Revit version, add-in dependencies and file-exchange method are confirmed before access
- Family geometry and parameter scope are agreed against intended schedules and views
- Code, permit and professional issue decisions remain with appointed parties

### Verified software and formats

- Autodesk Revit project and family files for agreed Revit workflows
- PDF and DWG documentation outputs where included in the issue protocol
- IFC exchange where explicitly required by the client
- Project-issued schedules and registers in the agreed tabular format

## 02 / Scope and gates

# Production stays reviewable.

Axys3D progresses work against named inputs. Design-bearing decisions and approvals remain client-led.

### Technical scope

- Model and family authoring
- Views, sheets, schedules and annotation support
- Cross-view documentation checks
- Model cleanup and package preparation

### 01 — Review template, model and sheet register

**Review gate:** Access gate: version, template, ownership and backup route accepted.

### 02 — Confirm worksets, ownership and file exchange

**Review gate:** Sample gate: representative family, view or sheet approved.

### 03 — Produce model and documentation tasks

**Review gate:** Production gate: cross-view and model-health checks recorded.

### 04 — Run consistency and model-health checks

**Review gate:** Issue gate: client approves revision and issue status.

### 05 — Return packages for client approval

**Review gate:** Handoff gate: files, logs and unresolved items acknowledged.

## 03 / Delivery definition

# Acceptance is part of handoff.

### Deliverables

- Revit model packages
- Families and governed content
- Drawing and schedule production support
- Issue and revision register

### Acceptance criteria

- Files open in the agreed Revit version without undeclared dependencies
- Views, sheets, schedules and content follow the issued standards
- Model-health, warning and known-issue status are transparently recorded
- Client checker accepts the package for the named documentation purpose

### Structured handoff

- Native Revit packages
- Published PDF/DWG/IFC where agreed
- Known-issue and assumption log
- Model health summary

### Evidence required

- Written scope approval
- Current source-information register
- Named client approvers
- Approved publication evidence

## Responsibility boundary

Revit and documentation production support only; design authorship, code compliance and professional issue remain with authorized project professionals.

Axys3D provides production, modeling, coordination or delivery support as scoped. It does not act as architect or engineer of record and does not provide statutory sign-off.

## Technical FAQ

# Scope questions, answered precisely.

### Can you join an established workshared model?

Yes, subject to an agreed access, ownership, sync and backup protocol.

### Can you coordinate documentation changes?

We support cross-view and drawing-set coordination against approved inputs; final design and issue approval remain client-led.

### Do you certify code or permit compliance?

No. We do not claim code certification, permit approval or statutory sign-off.

### How do you control families and shared parameters?

Against the client template, parameter schema, naming rules, intended schedules and an approved representative sample before wider production.
